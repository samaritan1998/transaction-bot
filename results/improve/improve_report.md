# 策略改进实验报告

只做模拟，不接券商、交易所或钱包。费用、滑点、T+1、一手 100 份与原回测相同。
参数只在训练段 2018-01-02 至 2023-12-29 上选择；测试段为 2024-01-02 至 2026-11-20。本报告数字全部由引擎跑出，没有手填。

## 实验纪律

- 本轮新试配置：**47** 种，分属 14 个策略族。每个族只取训练段（夏普优先，其次年化，再次回撤）最好的一组参数，再看测试段。
- 此前基线网格另有双均线 9 组、动量 3 组（见 `results/backtest/`），不计入本轮 47，但训练段已用过，存在多重检验负担。合计曾评估过的有参配置约为 59 组（12 组旧网格 + 47 组新配置）；无网格的固定搭配（如 60/40、40/40/20）已含在 47 内。
- 全部配置的测试段数字写在 `test_peek.csv`，**只作诊断，不参与选参**。
- 预先声明的「明显更好且稳健」门槛（须同时满足）：
  1. 测试段夏普 ≥ max(沪深300买入持有, 五只等权) + 0.15；
  2. 测试段最大回撤不比等权差过 5%；
  3. 测试段年化不低于两对照中较弱一方减 2%；
  4. 训练段夏普 ≥ 0.10；
  5. 测试窗内至少两个日历年的夏普不低于当年买入持有，且不出现远差于基准的灾难回撤。
- 越过门槛的策略只注册为 `run_daily.py` 的可选项，**不替换默认的五只 ETF 等权**，以免改动每个工作日 16:30 的自动任务。
- 国债 ETF 511010 单价约 141 元，一手约 1.4 万元，10 万元账户上的仓位较粗，这会反映在真实模拟里。
- 513100 纳指 ETF 的未复权价格在样本期内有过约 5 倍拆分痕迹；回测使用前复权。QDII 的场内溢价/折价与额度未建模，只按二级市场价格成交。

## 推荐结论

**找到了在测试段风险调整后、按预先门槛表现更好且相对稳健的新方案，但它们的优势主要来自加入国债和黄金，而不是把股票时机抓得更好。默认纸面策略仍然是五只 ETF 等权，先不自动切换。**

更具体的建议：

1. **若优先控制回撤、接受更低的股票仓位**：可选 `rp3_lb20`（股债金风险平价，波动率回看 20 日，每月再平衡）。测试段年化 7.45%、最大回撤仅 -2.01%、夏普 2.47，对照为买入持有 8.97% / -21.04% / 0.54，以及等权 9.85% / -21.55% / 0.56。训练段同样平滑（年化 4.19%、回撤 -3.88%、夏普 1.37）。按年冻结参数前推时，2021–2026 每一年收益都为正。**必须看清持仓结构**：训练段平均权重约 沪深300 7.8% / 国债 77.2% / 黄金 15.1%，测试段约 6.7% / 85.3% / 8.0%，最近一次再平衡（2026-11）国债权重已到约 91%。这基本上是低波动的债券组合外加一点黄金和很少的股票，不是「增强版股指策略」。测试段年化也没有超过等权。黄金 2024-01-02 至 2026-11-20 前复权累计约 +56%，对结果有很大贡献，未来不一定重复。同族的 `rp3_lb60`（训练段几乎一样好，测试段夏普 2.54、年化换手约 40% 低于 20 日的 96%）说明结论对回看窗口不敏感，但按纪律仍冻结训练段略优的 20 日。
2. **若希望仍保留明显的股票仓位、规则更简单**：可选 `perm_lite`（固定 40% 沪深300 + 40% 国债 + 20% 黄金，每月再平衡，没有可调参数）。测试段年化 8.69%、回撤 -14.48%、夏普 0.89，收益接近买入持有，回撤和夏普好于两个对照；训练段年化 3.01%、回撤 -15.71%、夏普 0.37，同样好于等权的训练段。换手很低（测试年化换手 32.9%）。缺点是 2026 年（至 11-20）仍亏约 9.7%–10.6%，因为 40% 的股票仓位跟上了股市调整；风险平价那一年是小赚的。
3. `rp4_lb20`（再加入纳指 ETF）测试段年化 8.15%、夏普 2.50，训练段夏普 1.56，也越过门槛。但多了 QDII 溢价与外汇未建模的风险，2022 年冻结参数前推小幅亏损。不是第一推荐。
4. `vol_ew_bond_tv8`（五只 ETF 等权按 8% 目标波动率缩仓，剩余进国债）也越过门槛，测试段年化 8.95%、回撤 -9.10%、夏普 0.83。但训练段夏普只有 0.16（刚过 0.10 的门槛），测试段 169 笔成交、年化换手约 120%，2022 和 2026 仍是亏的。不如上面两个干净。

**因此：不改 16:30 默认任务。** 若要在纸面账户里试用，把 `paperbot/config.py` 的 `PAPER_STRATEGY` 改成 `rp3_lb20` 或 `perm_lite`。请先备份或另开 `results/paper/paper_account.sqlite`，否则现有五只等权持仓会按新目标再平衡。问过用户之前，不要改默认值。

## LLM 新闻情绪因子：可行性

2026-11-22 实际探查 AKShare 1.20.65 的结果：

- `stock_news_em`（东方财富个股新闻）对 510300 只返回最近约 10 条，时间范围大约是 2026-11-02 至 11-19，是「当日最近 N 条」，不是 2018 年以来的完整历史。
- `stock_news_global_em` 大约最近 200 条，时间只到 2026-11-21 至 11-22。
- 新浪、财联社电报同样只有当天或最近几十条。
- `alternative_news_cctv` 可以按日取到 2016 年以来的新闻联播文本，但一天一次请求、没有现成的市场情绪分；用今天的模型去给旧新闻打分，会带入模型的世界知识，构成未来函数。当前环境也没有配置 LLM API 密钥。

**结论：现有公开新闻接口不足以对 2018–2023 做可信的情绪因子回测。没有编造历史情绪分。**

已另外写好只向前记录的框架：`paperbot/sentiment.py`。它每天拉取当前能拿到的标题，写入 `results/sentiment/forward_headlines.csv`，`sentiment_score` 栏留空，并且明确标记 `used_in_trading=no`。以后若有密钥和足够长的前瞻样本，再验证，不把未验证的分数接入交易。

为避免新闻接口超时或失败影响到每个工作日 16:30 的 `python run_daily.py`，情绪日志**没有**挂进每日任务；需要时单独运行：

```bash
cd /workspace/trading && .venv/bin/python -c "from paperbot.sentiment import append_daily_snapshot; append_daily_snapshot()"
```

## 风险说明

历史模拟不是对未来收益的承诺。扩展标的（黄金、国债、纳指 QDII）有自身的利率、商品、溢价、外汇和流动性风险；国债一手金额较大，实际权重会偏离目标。多重检验会让「最好的那一组」看起来好于真实的样本外期望。风险平价的高夏普在很大程度上是资产类别使然：若国债与黄金同时下跌，这条曲线不会再像测试段那样几乎不回撤。
